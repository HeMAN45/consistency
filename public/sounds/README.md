# Ambient audio

Drop loop files here, named exactly:

```
rain.m4a  thunder.m4a  waves.m4a  wind.m4a
fire.m4a  crickets.m4a  birds.m4a  people.m4a
```

`.mp3`, `.ogg` and `.wav` also work; the player tries each extension in turn.

Any file that is missing simply doesn't appear in the mixer, so you can add them
one at a time. Longer loops (30s or more) sound better, because a short loop
gives the ear a repeating pattern to lock onto.

Use CC0 or otherwise unrestricted audio only. This folder is served publicly and
ends up in the repository, so commercially released music does not belong here.
